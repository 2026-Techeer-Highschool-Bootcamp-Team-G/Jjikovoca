# 찍어보카 (Jjikovoca) 디자인 시스템

시험지를 찍고 형광펜으로 문지르면 AI가 단어장·오답노트를 만들고, 게임처럼 복습하게 하는 모바일 학습 앱. 이 저장소는 그 앱의 실제 프론트엔드 코드에서 추출한 디자인 시스템이다.

## 프로덕트

하나의 모바일 웹앱(390~480px 단일 컬럼). 마케팅 웹사이트·데스크톱 콘솔은 저장소에 없다.

핵심 플로우: 로그인 → 홈(D-day + 플래시카드) → 촬영(형광펜 제스처) → 단어장(태그별 자동 분류) → 학습(방식 3종 → 유형 2종) → 리포트 / 마이.

## CONTENT FUNDAMENTALS

**말투 — 해요체, 사용자를 주어로 두지 않는다.** 모든 안내문이 "~요"로 끝난다: "아직 카드가 없어요 — 시험지를 촬영해 첫 카드를 만들어보세요", "카드를 탭하면 뜻이 보여요", "학습을 준비하고 있어요…", "카드를 불러오지 못했어요". 명령형("확인하십시오")과 딱딱한 명사형("확인 필요")을 쓰지 않는다.

**"나"와 "너".** 1인칭은 소유 표현에만 쓴다("내 시험지로 만든 나만의 단어장", "마이페이지"). 2인칭 대명사는 등장하지 않고, 대신 동작 유도형 문장을 쓴다("시험을 등록하고 D-day·복습 일정을 받아보세요").

**빈 상태는 정직하게 + 다음 행동 한 개.** 가짜 숫자나 더미 카드로 화면을 채우지 않는다. 없으면 없다고 쓰고 바로 할 일을 붙인다: "아직 보관된 원문이 없어요 — 시험지를 촬영해보세요", "약점유형 분류는 준비 중이에요 (백엔드 연동 예정)".

**보상 문구는 숫자 + 즉시성.** "+40XP", "⚡ +5 XP", "연속 16일", "5개 복습 완료!". 과장 형용사("대단해요!") 대신 수치를 보여준다.

**구분자는 가운뎃점과 em dash.** 한 줄에 정보를 병렬할 때 " · " ("시험범위 기억률 68% · 오늘 복습 14개"), 문장 뒤 유도구는 " — " 로 잇는다.

**학습 동기 문구는 반말 격려체.** 로딩 화면 명언만 예외적으로 반말이며 따옴표 안 이탤릭으로 표시한다: "어제의 나보다 딱 한 걸음만 더 나아가자", "틀린 문제는 실력이 자라는 자리".

**대소문자·용어.** 영어 단어는 원문 그대로 소문자(inevitable), 발음기호는 대괄호([ɪnˈevɪtəbl]). 레벨은 "Lv.7 단어 헌터", 화폐는 "월 ₩4,900". 기능 이름은 한글 고정어: 단어장(구 오답노트), 원문 보관함, 일일 퀘스트, 졸업완료/복습대기/약점유형, 알아요/헷갈려요/몰라요.

**이모지는 쓴다 — 라벨 접두사와 상태 표식으로만.** 목록 제목 앞("📅 시험 일정", "📁 원문 보관함", "🔒 개인정보 처리방침", "🚪 로그아웃"), 국가 발음("🇺🇸 미국"/"🇬🇧 영국"), 카드 유형("🖍️" 단어 / "⬛" 문제), 보상("⭐", "⚡", "✨ AI 연상 이미지"), 반짝임("✦"), 카드 개념 이미지 폴백("⚖️", "📚"). 본문 문장 안에는 넣지 않는다.

**전체 분위기.** 토스(Toss)의 담백한 금융 앱 말투에 학습 앱의 게임적 보상을 얹은 톤. 조용하고 짧은 문장, 과하지 않은 응원, 숫자로 말하는 성취.

## VISUAL FOUNDATIONS

**색.** 파란색(`#3182f6`)이 유일한 주색이다. CTA·활성 탭·링크·강조 텍스트 전부 이 파랑이며, 연한 파랑(`#e8f3ff`)이 카드 배경·보조 버튼·태그를 맡는다. 형광펜 옐로우(`#ffd84d`)는 **악센트 전용** — 뜻 하이라이트, XP 바, 캡처 보상, 프리미엄 카드의 링크에만 쓰고 CTA로 쓰지 않는다. 중성색은 토스 계열 그레이 스케일(`#f9fafb` → `#191f28`). 상태색은 초록(성공/졸업)·노랑(주의/복습예정)·빨강(위험/오답)이 각각 fill + weak 쌍으로 존재한다. D-day 는 남은 일수에 따라 초록 → 연두 → 주황 → 빨강으로 바뀌는 별도 4단 스케일을 쓴다. 배경은 회색(`#f2f4f6`), 카드가 흰색으로 떠 있는 구조다. **다크 테마는 `[data-theme="dark"]` 스코프에 시맨틱 토큰만 다시 정의해 구현한다**(FR-17) — 표면은 `#121317`/`#1c1d23`/`#23252c` 3단, 브랜드 파랑은 `#4593fc` 로 한 단계 밝히고, 형광펜 옐로우는 라이트와 같은 `#ffd84d` 를 유지한다. 컴포넌트는 항상 시맨틱 변수만 참조하므로 테마 전환에 별도 분기가 없다. 자기평가 색은 알(파랑) · 헷(주황 `#e07a1e`) · 몰(빨강)의 `--color-rating-*` 3종, 학습 잔디는 초록이 아니라 브랜드 파랑 4단(`--color-grass-*`)이다.

**타입.** 전용 웹폰트를 번들하지 않고 시스템 한글 산세를 우선한다: `-apple-system, BlinkMacSystemFont, 'Apple SD Gothic Neo', Pretendard, system-ui`. 굵기는 400/500/700 세 단계만. 크기는 10~28px 실측 스케일(탭 라벨 10, 배지 11, 캡션 12, 부제 13, 본문 15, 카드 제목 16, 리스트 제목 17, 페이지 제목 22, 단어 28). 행간은 1.5~1.6, 제목은 1.2. 글자 간격 조정은 하지 않는다.

**배경.** 사진·일러스트·패턴·텍스처가 없다. 전면 배경은 회색 단색이고, 유일한 그라데이션 사용처는 ① 로고(파랑 세로), ② 형광펜 마커(옐로우 세로), ③ 카드 상단 개념 이미지 영역(연파랑→연민트 가로), ④ 프리미엄 카드(잉크 네이비 가로), ⑤ 로그인/온보딩 상단(연파랑→흰색 세로), ⑥ XP 바(옐로우). AI 연상 이미지는 서버에서 생성되며, 없으면 이모지로 폴백한다 — 임의의 일러스트를 그려 넣지 않는다.

**카드.** 흰 배경 + 1px `#e5e8eb` 테두리 + radius 12~20px. 목록 카드는 radius 12, 그림자 없음(선택/재생 중에만 1.5px 파란 테두리). 플래시카드는 radius 20 + `0 8px 24px rgba(0,0,0,.12)`. 정보 카드(D-day·프리미엄)는 radius 14. 모달·바텀시트는 radius 16/20 상단. 좌측 컬러 보더는 **정답/오답 결과 표시에만** 4px 로 쓴다(그 외 용도로 쓰지 않는다).

**그림자.** 4종만 있다: 카드 `0 2px 8px rgba(0,0,0,.08)`, 플래시카드 `0 8px 24px rgba(0,0,0,.12)`, 모달 `0 8px 24px rgba(0,0,0,.16)`, FAB `0 5px 12px rgba(14,61,140,.35)`(파란 잉크 그림자). 내부 그림자(inset)는 쓰지 않는다.

**투명도·블러.** 백드롭 블러를 쓰지 않는다. 알파는 오버레이(dim 0.6 / 다이얼로그 0.4), 이미지 위 라벨 배경(흰색 0.85), 어두운 카드 위 보조 텍스트(흰색 0.5~0.65), 밝은 카드 안 구분선(흰색 0.7)에만 쓴다. 텍스트 본문은 알파를 섞지 않고 정해진 3단계 색을 쓴다.

**간격·레이아웃.** 4의 배수 스케일(4·8·12·16·20·24·32). 화면 좌우 여백은 항상 20px, 카드 사이는 8~12px. 앱 최대 폭 480px, 중앙 정렬. 고정 요소: 하단 탭(82px + safe-area)과 그 위에 떠 있는 주 CTA(bottom 108px). 하단 탭 중앙에는 56px 로고 FAB 이 16px 돌출한다. 상단 바 56px, 최소 터치 영역 44px.

**애니메이션.** 모션이 브랜드의 큰 부분이다. 이징 3종: 표준 `cubic-bezier(.4,0,.2,1)`(탭 인디케이터 280ms), 플립 `cubic-bezier(.2,.8,.3,1)`(카드 3D 플립 500ms), 스프링 `cubic-bezier(.2,.9,.3,1.2)`(성공 팝 600ms, 오버슈트). 종류는 ① 촬영 계열(스캔 라인, 노란 엣지 글로우, 화이트 플래시 120ms, 스파클 버스트, XP 칩 상승), ② 성공 계열(스프링 팝 + 퍼지는 링 + 컨페티 + 순차 rise-in), ③ 주의 환기(브랜드 글로우 숨쉬기, 주기적 흔들림, 콤보 불꽃), ④ 로딩(스피너, 시머 스윕, 통통 튀는 점, 호흡하는 포커스 링), ⑤ 형광펜(밑줄 좌→우 쓸기, 잉크 시머). 페이드만 쓰는 정적 전환은 오버레이 등장(200ms)과 시트 상승(250ms)뿐이다. 키프레임 이름은 `jjik-*` 접두사를 유지한다.

**호버·프레스.** 모바일 앱이라 호버 상태가 없다. 대신 프레스 피드백을 쓴다: 카드 행은 `scale(0.98)`(120ms), 비활성 버튼은 opacity 0.4, 선택 상태는 배경색/테두리색 전환(160ms). 색을 어둡게/밝게 하는 호버 규칙은 정의되어 있지 않으므로 웹에서 쓸 때는 `--color-brand-strong`(#2272eb)을 눌림·호버 색으로 쓴다.

**테두리.** 1px `#e5e8eb` 가 기본, 강조/선택은 1.5px 브랜드 파랑, 유도형 빈 상태는 1px dashed. 구분선도 같은 1px 회색.

**보호 그라데이션 vs 캡슐.** 이미지 위 텍스트에 그라데이션 보호막을 깔지 않고, 흰색 0.85 알파 캡슐(radius 999)을 쓴다("✨ AI 연상 이미지").

**이미지 톤.** 브랜드 이미지 자산이 없다. 앱이 보여주는 이미지는 두 종류뿐이다 — 사용자가 찍은 시험지 원문(중성·있는 그대로, `objectFit: cover`, radius 12)과 AI 연상 이미지(연파랑~연민트 배경 위). 필터·그레인·색보정은 적용하지 않는다.

**형광펜 모티프.** 제품 이름과 로고가 곧 이 시스템의 정체성이다. 뜻·정답 같은 "알아야 하는 것"은 `linear-gradient(transparent 55%, #ffd84d 55%)` 로 칠한다. 밑줄·굵게·색 변경보다 이 하이라이트를 먼저 쓴다.

## PLATFORM CONSTRAINTS — React + Capacitor 앱 스토어 배포

이 제품은 React 웹앱을 Capacitor 로 감싸 App Store / Google Play 에 배포한다(요구사항 §5-2·§7). 디자인 판단에 직접 영향을 주는 항목만 옮긴다.

**Safe-area 는 디자인 단계에서 계산한다.** 상단 바와 하단 탭은 노치·다이내믹 아일랜드·홈 인디케이터를 침범할 수 없다. `--safe-top/bottom/left/right` 와 파생 토큰(`--layout-header-offset`, `--layout-bottom-nav-offset`, `--layout-cta-bottom`)을 쓰고, 화면 높이를 `100vh` 로 고정하지 않는다. 하단 고정 CTA는 탭 위 108px + safe-bottom 위치가 기준이다.

**네이티브 제스처와 충돌하지 않게.** iOS 스와이프 뒤로 가기가 살아 있어야 하므로 화면 좌측 가장자리(약 20px)에 가로 스와이프·드래그 인터랙션을 두지 않는다. 좌우 스와이프 캐러셀은 화면 안쪽 영역에서만.

**웹 래핑처럼 보이면 심사에서 반려된다.** 브라우저 UI 관용구(주소창 느낌의 헤더, 링크 밑줄, hover 의존 상태, 새 탭 열기)를 쓰지 않는다. 상태 표현은 프레스 피드백(scale 0.98 / 배경 전환)으로, 화면 전환은 60fps 를 유지할 수 있는 transform·opacity 애니메이션으로 한다.

**흰 화면 금지.** 오프라인·요청 실패는 `OfflineNotice`, 데이터 없음은 `Placeholder`, 대기는 `StudyLoading`. AI 분석처럼 오래 걸리는 작업은 즉시 크롭 애니메이션 + 대기열 스피너로 체감 지연을 가린다(`CaptureFlash`, `StudyLoading`).

**결제 UI 는 네이티브 IAP 만.** `PlanCard` 를 쓰는 결제 화면에는 갱신 주기·해지 방법·이용약관·개인정보처리방침 링크를 함께 노출한다. 외부 PG 링크나 "웹에서 결제하기" 같은 아웃링크 버튼은 만들지 않는다(가이드라인 위반). 소셜 로그인을 붙이면 'Apple로 로그인'을 같은 비중·같은 위치 계층으로 둔다.

**계정 탈퇴는 앱 안에서.** 마이 → 회원 탈퇴는 외부 웹으로 내보내지 않고 앱 내 화면에서 즉시 파기까지 끝낸다.

**권한 요청은 맥락 안에서.** 카메라·갤러리·알림 권한 팝업을 첫 실행에 띄우지 않는다. 촬영 버튼을 누른 순간, 시험 D-day 등록을 마친 순간처럼 필요성이 드러난 화면에서 요청하고, 거부 시 대체 화면(갤러리에서 고르기 등)을 준비한다.

**네이티브 플러그인에 의존하는 기능.** 발음 오디오는 네이티브 TTS, 시험지 PDF 는 Filesystem + Share 시트로 처리한다 — 그래서 PDF 버튼의 결과는 "다운로드"가 아니라 **OS 공유 시트**이고, 문구도 "PDF 만들기 → 저장·공유"로 쓴다. `<a download>` 스타일 UI 를 그리지 않는다.

## ICONOGRAPHY

- **자체 인라인 SVG 세트 하나만 쓴다.** 원본 `web/src/shared/ui/icons.tsx` 의 19개 글리프를 `components/core/Icon.jsx` 에 이름 기반으로 이식했다. 24px 그리드, 2px 스트로크, 라운드 캡/조인, `fill="none"`, `stroke="currentColor"` — 토스 스타일 라인 아이콘이다. Lucide·Heroicons 등 외부 아이콘 폰트나 CDN은 쓰지 않는다(형태가 비슷해 보여도 섞지 말 것).
- 세트: menu, search, bell, clock, calendar, fire, check, refresh, trophy, chevron-right, chevron-left, close, speaker, home, book, vocab(펼친 책), chart, user, camera.
- 크기 규칙: 하단 탭 24 · 헤더 20~22 · 인라인 18~20 · 목록 화살표 14~16.
- **아이콘 폰트·PNG 아이콘·스프라이트는 없다.** 저장소에 아이콘 이미지 파일이 전혀 없으므로 새로 그리지 말고, 세트에 없는 개념은 이모지 접두사나 텍스트 라벨로 처리한다(앱도 그렇게 한다: 📅 📁 🔒 🚪 ⭐ ⚡ ✨ 🖍️ ⬛ ✦ ›).
- 유니코드 문자를 아이콘처럼 쓰는 자리가 있다: `›`(이동), `✓`(선택/성공), `✦`(반짝임), `▾`(정렬 드롭다운).
- **로고**: `assets/logo.svg` (= `components/core/AppLogo.jsx`). 파란 라운드 스퀘어 + 흰 뷰파인더 브래킷 8개 + 기울어진 노란 형광펜 스트립. 워드마크 이미지 파일은 원본에 없다 — 로고타입이 필요하면 "찍어보카"를 20px/700 브랜드 파랑 텍스트로 적는다.

### 의도적 추가

- `Icon` — 원본은 `IconHome`, `IconSearch` 처럼 글리프마다 별 컴포넌트를 export 한다. 같은 SVG 를 이름 인자로 고르는 래퍼 하나로 묶었다(글리프 경로는 원본 그대로).
- UI 키트의 `NotificationsScreen` — 셸 내비게이션이 끊기지 않게 두었다.
- `ReportScreen` — 원본 코드에는 아직 화면이 없지만 FR-09 가 지표(새 단어·정답률·주간 학습 시간·약한 단어 Top3)를 명시하므로 그 지표만으로 구성했다. 임의의 지표를 추가하지 않았다.
- `SegmentedControl` · `OfflineNotice` — FR-17(테마 3지 선택)과 NFR 5-1(오프라인 방어)을 구현할 프리미티브가 원본에 없어 추가했다.

### 만들지 않은 것

원본에도 요구사항에도 대응물이 없는 프리미티브(Toast, Avatar, Switch, Select, Tooltip 등)는 추가하지 않았다. 슬라이드 템플릿도 없다. 푸쉬 알림 설정(FR-20)·모니터링 대시보드(FR-21~25)는 앱 UI 범위가 확정되지 않아 화면을 만들지 않았다.

## 대체·보류 항목

- **폰트 파일 없음.** 원본은 웹폰트를 번들하지 않고 시스템 폰트 스택에 의존한다. `Pretendard Variable` 만 jsDelivr CDN 으로 선언해 비-애플 환경에서도 근사한 렌더를 얻게 했다. `Apple SD Gothic Neo` 는 macOS/iOS 시스템 폰트라 파일이 없다. 브랜드 전용 폰트를 쓸 계획이 있다면 파일을 주면 교체한다.
