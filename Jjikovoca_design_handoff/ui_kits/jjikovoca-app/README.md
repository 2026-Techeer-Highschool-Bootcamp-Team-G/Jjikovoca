# 찍어보카 앱 UI 키트

`web/` (Vite + React, FSD 구조) 의 실제 화면을 디자인 시스템 컴포넌트로 재현한 클릭 스루. 화면 구성은 요구사항 v3.2 기준으로 보정했다.

- `index.html` — 폰 프레임(390×844) 안에서 전체 플로우를 실행. 아래 세그먼트로 라이트/다크/시스템 테마와 오프라인 상태를 바꿔볼 수 있다
- `LoginScreen.jsx` — 01 로그인 (`pages/login/ui/LoginPage.tsx`)
- `HomeScreen.jsx` — 03 홈: D-day + 플래시카드 캐러셀 (`pages/home`, `widgets/recent-cards`)
- `VocabScreen.jsx` — 06 단어장: 태그 필터 탭 · 알/헷/몰 누적 · 몰라요 빈도순 정렬 · 태그 편집 시트 (FR-04·FR-18)
- `StudyScreen.jsx` — 학습: 복습 방식 3종 → 퀴즈 유형 2종 → 플래시카드/빈칸 → 알헷몰 평가 → 완료 (FR-10·FR-12·FR-05·FR-06)
- `ReportScreen.jsx` — 리포트: 정답률 도넛 · 주간 학습 시간 · 학습 잔디 · 약한 단어 Top3 (FR-09·FR-14)
- `MyScreen.jsx` — 14 마이: 프로필 · 성장 · 활성 시험 자동 태깅 · 화면 테마 · 구독 플랜 (FR-11·FR-17·FR-19)
- `App.jsx` — 셸(하단 탭, 촬영 FAB 이펙트), 알림 화면, 테마·오프라인 토글
- `data.js` — 가짜 단어 5개(태그·알헷몰 포함), 태그 탭, 리포트 지표, 플랜, 사용자 정보

재현하지 않은 화면: 촬영/크롭 형광펜 제스처 플로우(`features/capture`), 시험지 PDF 내보내기, 결제 완료·영수증 검증, 푸쉬 알림 설정, 모니터링 대시보드. 촬영 플로우는 카메라 스트림과 제스처 크롭에 의존해 정적 재현 가치가 낮고, 나머지는 요구사항에 화면 설계가 아직 없다.
